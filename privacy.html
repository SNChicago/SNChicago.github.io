Privacy policy

Applies to: "rclone (personal backup app)", a private Google Cloud project that has one user, its owner.

What the app accesses

The app uses the Google Drive permission drive.file. With this permission the app can see and change only the files and folders that the app itself created. It cannot see any other file in the owner's Drive. It does not read email, contacts, calendar or any other Google service.

What the app does with the data

The app copies files from the owner's computer into one Drive folder, and it lists and checks the files that it created there. The data stays between the owner's computer and the owner's Google Drive. The app does not send data to any other party, does not sell it, does not use it for advertising, and does not use it to train AI models. No person other than the owner reads the data.

What the app stores

The sign-in token that Google issues is stored only on the owner's computer, in the configuration file of rclone. This site collects nothing.

Limited use

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Changes

If the app's use of Google data changes, this page changes first.
